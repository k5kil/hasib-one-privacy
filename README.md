# ملفات سياسة الخصوصية لتطبيق حاسب ون

- ارفع `index.html` إلى جذر مستودع GitHub عام.
- فعّل GitHub Pages من Settings > Pages.
- اختر Deploy from a branch ثم `main` و`/(root)` ثم Save.
- رابط الصفحة سيكون عادةً: `https://USERNAME.github.io/hasib-one-privacy/`

قبل النشر:
1. استبدل `YOUR_SUPPORT_EMAIL@example.com` ببريد دعم حقيقي.
2. راجع أذونات التطبيق ومكتبات Flutter وAndroid وAndroid Auto Backup.
3. تأكد أن السياسة تصف سلوك التطبيق الفعلي بدقة.
